# TAREA-MODULO-3.--Descarga-inspecciona-y-borra-im-genes
En esta práctica he aprendido a descargar imágenes de Docker Hub, consultar sus características, guardar su información en un archivo de texto, crear contenedores y eliminar imágenes. También he comprobado que es necesario eliminar los contenedores que utilizan una imagen antes de poder borrarla.
